##NEbrow: путь в Интернет

Лёгкий браузер на движке Chromium. Ничего лишнего: открывайте страницы во вкладках, ищите прямо из адресной строки и скачивайте файлы с понятным списком загрузок.

Что умеет

Вкладки. Ссылки, которые сайты открывают в новом окне, появляются новой вкладкой.
Одна строка для адреса и поиска. Введите адрес или просто запрос, поиск идёт через DuckDuckGo.
Загрузки со списком: прогресс, кнопки «Открыть» и «В папке» (на компьютере), уведомление о завершении (на Android).
Вход на сайтах сохраняется между запусками.
Горячие клавиши на компьютере: Ctrl+T, Ctrl+W, Ctrl+L, Ctrl+R, Ctrl+J, Alt+←/→.

Где работает: Windows (установщик), Linux (.deb и .tar.gz), Android (.apk).

Версия 0.1.0: это первая публичная сборка, закладок, истории и расширений пока нет.
